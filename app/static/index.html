¿Cómo comprobarlo?

  1. Conecta la aplicación a PostgreSQL.
  2. Agrega algunos registros.
  3. Crea un backup completo y descárgalo.
  4. Comprueba SHA-256 y ejecuta el workflow de restauración en GitHub Actions.

Las copias guardadas dentro de Render son temporales: conserva los archivos descargados.
